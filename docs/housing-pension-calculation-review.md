# 주택연금 월지급금 계산기 검토 (최종: 2026-11-08)

대상: `public/static/app.js` 의 `calcHousingPension()` / 위젯 `src/pages/ArticlePage.tsx`(`#hp-calc-widget`), 글 `housing-pension-calculation`

## 1. 적용한 공식 자료와 범위
| 항목 | 내용 |
|---|---|
| 자료 | 한국주택금융공사(HF) 「월지급금 일람표」 엑셀, **2026.6.1 신청접수분** (https://www.hf.go.kr/ko/sub03/sub03_01_01_02.do) |
| 지급방식 | **종신지급방식 · 정액형** 만 계산 (초기증액형·정기증가형·대출상환방식은 공식 값을 확인하지 못해 제외, 화면에서 공식 예상연금조회로 안내) |
| 나이 기준 | 부부 중 **연소자** 만 나이, 55~90세 (1세 단위) |
| 주택가격 | 1~12억원 (1억 단위 표). 범위 밖 입력은 오류 안내 후 계산하지 않음 |
| 주택 유형 | 일반주택, 주거목적 오피스텔 (표가 서로 다름) |
| 노인복지주택 | HF 웹 「월지급금 예시」(2026.03.01 기준) 5세 단위(55~80세) 표. 81세 이상은 계산하지 않음 |

## 2. 공식 표 대조 결과
- 일반주택 432칸 + 오피스텔 432칸 = **864칸 전부 공식 엑셀과 일치 (864/864)**.
- 일반주택·오피스텔 일반형은 HF 웹 「월지급금 예시」(2026.03.01 기준)와도 전 구간 일치.
- 노인복지주택 표는 5세 단위 값만 공식이며, 그 사이 나이는 보간값.

## 3. 표 사이 금액 계산(직선 보간)
- 주택가격이 정확히 1·2·…·12억이고 나이가 표에 있는 값이면 **공식 값 그대로** → 화면 배지 "공식 일람표 값 그대로".
- 그 외(예: 3.5억, 노인복지주택 72세)는 **인접한 두 공식 값을 직선으로 이어 계산** → 배지 "근사값 · 공식표 사이를 직선 보간", 라벨 "예상 월지급금 (근사값)", 확정 금액이 아니라는 문구 표시.

## 4. 오차 가능성 (직접 계산한 추정치, 공식 수치 아님)
- **상한 부근**: 월지급금에는 상한이 있어 일부 나이·가격 구간에서 표 값이 평평해집니다. 상한이 구간 한가운데서 시작되면 직선 보간이 실제와 달라질 수 있으며, 추정 최대 오차는 **약 3%** (예: 일반주택 85세 7~8억 구간). 이런 구간은 화면에 "상한에 걸려 실제와 차이가 더 클 수 있음" 경고를 추가로 표시(전 조합의 약 4.5%, 722/15,912 해당).
- **노인복지주택 나이 보간**: 일반주택 표로 같은 5세 단위 보간을 흉내 낸 대리 지표 기준 평균 약 0.8%, 최대 약 2.8%. 노인복지주택 실제 오차는 아님.
- 가격이 표 값(정수 억)에 가까울수록 오차는 작습니다.

## 5. 안내 문구 (화면)
- "공식 확정 금액이 아닙니다. 실제 월지급금은 가입 시점의 주택가격(감정평가), 부부 나이, 지급방식에 따라 달라지며 한국주택금융공사 예상연금조회로 확인하세요."
- 정액형 이외 방식은 공식 예상연금조회 링크로 안내.

## 6. 입력 검증·UI (Playwright, PC 1280 / 모바일 390)
- 공식값 3건, 근사값 2건, 오류 6건(가격 하한·상한, 나이 하한·상한, 노인복지주택 81세, 빈 입력) 모두 통과. 모바일에서 버튼 가림·JS 오류 없음. 가격 입력 한글 미리보기(35000 → "3억 5천만원") 정상.

## 7. 남은 한계
- 초기증액형·정기증가형·우대지급방식 금액은 계산하지 않음(공식 값 미확인).
- HF 일람표가 개정되면 표를 다시 대조해야 함(다음 점검: 일람표 신규 기준일 공지 시).
- 기존 글 본문 표(3억·5억·7억, 70세: 92.3 / 153.9 / 215.5만원)는 계산기 표의 70세 값(923 / 1539 / 2155천원)과 **일치** 확인(2026-11-08).
